# ECInfo CALL 系统原型 2.0

本目录是当前主原型，定位为 2.0 版本。它基于 1.0 归档原型 `archive/prototype-1.0/` 保留页面和交互逻辑，并进行完整视觉升级。

## 打开

直接在浏览器打开本目录 `index.html`，或运行 `python3 server.py 18766` 后访问 `http://localhost:18766`。

## 改动边界

- 1.0 原版位于 `archive/prototype-1.0/`，本目录是当前评审入口。
- 新版 HTML 只增加一条 `ui-upgrade.css` 样式引用；原有页面结构、文字、模拟数据、所有 JavaScript 脚本逐字保留。
- UI 升级全部集中在 `ui-upgrade.css`：导航、首页、表格、表单、弹窗、抽屉、登录、移动工作台及明暗主题。
- 原有角色权限、业务规则、按钮事件、状态流转、导入导出与本地存储逻辑不变；不增加后台或真实接口。
- 窄屏登录页面可纵向滚动；移动端仍保留原有师傅/主管工作台、底部导航与现场处理抽屉。

原型仍使用模拟数据与浏览器本地存储，不是生产系统。原型账号密码行为沿用原版，视觉升级不改变其安全边界。同一域名下新旧版本沿用相同的本地存储键；如需隔离演示数据，请使用不同端口或浏览器配置。

每批先由团队核对需求与流程、走查实际原型，整理断点与候选方案；业务不清楚时先逐项问用户，用户也回答不了或复核后仍有缺口的部分记录后再集中问客户。已明确部分内部整改并复测，形成可解释、可演示的方案后，再请客户确认范围和真正未决的规则。客户选择后补齐受影响的交互，执行业务验收并记录冻结版本。澄清不能称为定稿签收，也不由AI自动对外联系。

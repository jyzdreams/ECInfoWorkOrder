## 3. P / 普通报价维修流程

```text
客户需求
→ 报价任务
→ 报价组维护报价版本
→ 客户确认最终报价
→ 报价组确认中单
→ 系统按成交报价材料自动生成 MR
→ 库存 / 采购 / 备货
→ 材料就绪
→ CR / 主管与客户确认正式施工时间
→ 师傅施工
→ 客户确认或签名
→ 师傅交回完工纸CP（维修清单）
→ 主管先收件/核对
→ 主管确认完工，更新维修状态
→ 其他角色按权限查看；财务独立核资料/开票收款
```

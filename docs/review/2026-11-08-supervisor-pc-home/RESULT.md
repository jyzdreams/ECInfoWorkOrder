## 设计与功能

- 顶部：我的工作台、当前主管姓名、角色与区域。
- 第一层：待我处理、进行中、异常提醒，三张统计卡；点击切换下方任务列表。
- 第二层：左侧我的待办为主体，右侧快捷操作；取消主管首页原八卡三列及最近来电区块。
- 第三层：相关任务最近动态，依源更新时间排序，最多五条；历史演示资料不标为今日。
- 颜色沿用现有 EC 蓝 #2990d0、深蓝 #122d45、品牌琥珀色 #fbb000；字体、边框与页面外壳复用品牌样式。

| 入口 | 现有功能及数据依据 |
| --- | --- |
| 待我处理 | 分派中心 pending、pendingApproval、pendingCompletion；完工确认优先，最多预览6条，超出显示总数与全部任务入口 |
| 进行中 | 分派中心 assigned，同一组待接单／处理中／已分派任务 |
| 异常提醒 | 上述未结任务中的 urgent、rejectReason、既有无法完成标签；可与待办／进行中重叠，不虚构SLA或新状态 |
| 待办及动态逐条点击 | 复用分派中心 showDispatchTaskDrawer 任务详情，包括 CALL 和直接分派任务；详情沿用原有查看模式 |
| 安排分派 | 分派中心 pending 页签，含接单申请 |
| 完工确认 | 分派中心 pendingCompletion 页签；该页沿用既有“已確認”标签，本轮未改状态或业务命名 |
| 跟进进度 | 分派中心 assigned 页签 |
| 查阅服务单 | 现有 srFolder 页面，保留现有显示名称与功能 |
| 查看全部任务 | 分派中心 all；进行中视图进入 assigned |
| 最近动态 | 分派中心同一主管名下，以及同区未指定有效主管的任务；不显示全局来电和其他主管记录 |

主管 PC 登录默认进入已有权限范围内的 dashboard。切换角色规则、移动入口、权限表和业务处理函数不变。getDispatchBuckets 增加默认开启的补编号参数，主管首页传 false 只读复用；其他原调用保持原行为。首页未新增持久化业务数据、接口或业务操作。

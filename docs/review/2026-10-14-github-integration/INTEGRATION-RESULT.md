## 6. 合并衔接修正

1. 新布局保留QUO负责人候选、保固控件、有效期空值保存及当前交付只读段，避免以旧远端表单覆盖本地字段。
2. 物料名称下拉保存货品编号时，MR payload传实际货品编号；服务器关联查询读取code，避免前端选产品后仍按DEMO编号/名称错误关联。
3. 移动搜索以选中师傅标识判断是否重建确认区，重建前保存备注；修正远端只比较“是否有有效师傅”的判断遗漏换人场景。PC筛选视图补全statusFilter，清除被过滤掉的候选。
4. 报价分页复用本地一次绑定逻辑；只补重绘后的打印、历史、电话事件，不重复绑定分页。测试预览反复打开只存在一个窗口。
5. 报价打印保留客户档案/工单地址、原Our Ref含义；未把师傅/报价负责人姓名伪作已签署签名，未把零单价自动说成Included。保存总额为0（100%折扣）时打印0，不回退原总价。
6. 打印Logo与远端原件哈希一致；补齐Pages的根目录和prototype子目录Logo打包及触发清单。仅修改配置，没有执行或触发发布。

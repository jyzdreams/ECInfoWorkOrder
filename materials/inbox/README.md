# 待整理输入资料

新收到的客户文件、截图、压缩包和会议附件统一先放这里。同名文件放到按收件日期区分的子目录，保留原文件名和内容，不覆盖已有文件。

处理人先记录收件日期、提供人、来源及待整理状态，再登记到[来源索引](../../docs/knowledge/01-source/SOURCE-INDEX.md)。按类型归入听记纪要、溝通筆記、纸质材料图片或参考文档；移动前查引用、查重，移动后核对内容和路径。

客户原件不重命名，不恢复已失效的materials/raw/。提取、转换和清洗文件与原件分开，记录原件路径；临时解析产物放.codex/，有长期价值的整理结果按docs六类保存。

这里的文件不作为当前需求基线，也不直接发给客户。

登记、归类不等于客户批准，协作方式见[团队协作规范](../../docs/governance/TEAM-COLLABORATION.md)。store/仅供用户临时存放，不另作为正式客户收件入口。
